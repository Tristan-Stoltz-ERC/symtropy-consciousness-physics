# GeoBio Foundry research prototype

This directory contains the GeoBio Foundry research programme, current SOTA gap analysis, benchmark protocol, evidence-aware resource schema, and first offline reference kernel.

- [Research programme v0.1](RESEARCH_PROGRAMME_v0.1.md)
- [State-of-the-art gap analysis — 15 November 2026](SOTA_GAP_ANALYSIS_2026-11.md)
- [GeoBioBench evaluation protocol v0.1](BENCHMARK_PROTOCOL_v0.1.md)
- [Evidence-aware resource-flow schema](GEO_RESOURCE_SCHEMA_v0.1.json)
- [Rust reference kernel](kernel/)
- [Implementation and validation status](IMPLEMENTATION_STATUS.md)

The initial software scope is elemental resource accounting and evidence-state discipline. It does not model certified pressure vessels, geomechanics, live biological processes, or flight systems. The Rust kernel is authored but has not yet been compiled or tested in this environment.
