# GeoBio Foundry research prototype

This directory contains the GeoBio Foundry research programme and the first offline benchmark kernel. It is deliberately isolated from the production Symtropy library while the domain model and evidence contract are being validated.

- [Research programme v0.1](RESEARCH_PROGRAMME_v0.1.md)
- [Implementation status](IMPLEMENTATION_STATUS.md)

The initial software scope is resource accounting and evidence-state discipline. It does not model certified pressure vessels, geomechanics, live biological processes, or flight systems.
